บทที่ 8 — Loss: ตัวเลขตัวเดียวที่บอกว่า “เราผิดแค่ไหน”

สำหรับงานจำแนก เราใช้ cross-entropy loss — สำหรับภาพหนึ่งภาพที่มีคลาสจริง c และความน่าจะเป็นที่ทำนายได้ pc

loss = − log p_c
⭐ สิ่งที่ต้องจำ cross-entropy ลงโทษความผิดพลาดที่มั่นใจหนักที่สุด ซึ่งเข้ากับการแพทย์พอดี เพราะคำตอบที่ผิดอย่างมั่นใจคืออันตรายที่สุด
⚠️ แยกให้ออก loss คือสิ่งที่โมเดล optimize ส่วน sensitivity, specificity, AUC คือสิ่งที่แพทย์สนใจ — มันเกี่ยวข้องกัน แต่ไม่ใช่สิ่งเดียวกัน

บทที่ 26 — วัดความซ้อนทับ: Dice และ IoU ⭐ สูตรที่ต้องคำนวณได้

Dice = 2|A ∩ B| / (|A| + |B|)        IoU = |A ∩ B| / |A ∪ B|
A = mask ของผู้เชี่ยวชาญ   ·   B = mask ของโมเดล
⚠️ ทำไมไม่ใช้ pixel accuracy เนื้องอกที่กินพื้นที่ 1% ของภาพ ทำให้ mask ว่างเปล่าได้ accuracy 99%
⭐ ตัวอย่างที่ต้องคำนวณได้ ผู้เชี่ยวชาญวาด 100 พิกเซล · โมเดลวาด 80 พิกเซล · ซ้อนทับ 60 พิกเซล → Dice = 2 · 60 / (100 + 80) = 0.67 และ IoU = 60 / (100 + 80 − 60) = 0.50

⭐ ความจริงเรื่องงบ เวลาของผู้เชี่ยวชาญคือคอขวด — ให้ติด label กับข้อมูลที่ถูกต้อง (หลากหลาย ยาก เป็นตัวแทน) ไม่ใช่ติด label กับข้อมูลที่มากที่สุด

คุณภาพของ label และความสอดคล้องระหว่างผู้อ่าน

⚠️ รังสีแพทย์ผู้เชี่ยวชาญสองคนมักเห็นไม่ตรงกัน — “ความจริงพื้นฐาน” จึงไม่แน่นอนในตัวมันเอง

  • ⭐ เขียนแนวทางการติด label พร้อมภาพตัวอย่างและเคสก้ำกึ่ง เช่น “น้ำในเยื่อหุ้มปอดนิดเดียวนับเป็นบวกไหม”
  • ⭐ ให้ผู้อ่านสองคนขึ้นไปติด label กับข้อมูลส่วนหนึ่ง แล้วตัดสินข้อขัดแย้งด้วยฉันทามติหรือผู้อ่านอาวุโส
  • ⭐ วัดความสอดคล้องด้วย Cohen’s kappa (สองผู้อ่าน · ข้อมูลเป็นหมวด) หรือ Dice ระหว่าง mask ของทั้งคู่
κ = (p_o − p_e) / (1 − p_e)
p_o = ความสอดคล้องที่สังเกตได้   ·   p_e = ความสอดคล้องที่คาดว่าจะเกิดจากความบังเอิญ
⭐ จุดสำคัญ โมเดลไม่มีทางดีกว่า label ที่ใช้ตัดสินมันได้อย่างน่าเชื่อถือ ⚠️ ถ้าผู้อ่านเห็นตรงกันแค่ระดับปานกลาง “ความผิดพลาด” ของโมเดลส่วนหนึ่งอาจเป็นสัญญาณรบกวนใน label เอง
